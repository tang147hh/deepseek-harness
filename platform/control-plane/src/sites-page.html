发布静态站

只打包当前用户 workspace/sites/<name> 到不可变快照。公网站点不读直播 workspace，也不带登录 Cookie。

Agent UI · 文件 · 插件组合 · 登出

必须有 index.html。拒绝 .env、.credentials.yaml、*.pem、*.key。整站默认 ≤ 20MB。

写令牌只显示一次（首次发布或点「轮换」）。它不是登录 session，也不能换用户 JWT。公网 KV 只在站点域：静态页用同源 fetch('/v1/kv/…')，不要打 APP_HOST（带不上、也不该带 app Cookie）。
